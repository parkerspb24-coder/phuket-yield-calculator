# Калькулятор доходности недвижимости на Пхукете · Этажи

Одностраничный калькулятор доходности аренды под бренд агентства «Этажи Пхукет».
Считает чистую прибыль, годовую доходность и срок окупаемости в трёх сценариях
для краткосрочной и долгосрочной аренды.

Весь калькулятор — один файл `index.html`. Vanilla JS + CSS, без сборки и фреймворков.
Единственная внешняя зависимость — шрифты Google Fonts (Unbounded + Manrope).

## Файлы

| Файл | Зачем |
|---|---|
| `index.html` | Сам калькулятор. Всё внутри: разметка, стили, логика, фирменный знак инлайн-SVG |
| `og.png` | Превью для соцсетей 1200×630 |
| `og-source.html` | Исходник превью. Открыть в браузере в окне 1200×630 и снять скриншот в `og.png` |
| `logo.svg` | Фирменный знак Этажей отдельным файлом (в `index.html` он уже вшит инлайном) |

## Как поменять цвета

Все цвета живут в одном блоке `:root` в начале `<style>` внутри `index.html`.
Перекраска под другой филиал — правка только этого блока, больше нигде цвета не захардкожены.

```css
:root{
  --void:#0E1113;    /* фон страницы */
  --panel:#161A1D;   /* карточки */
  --panel-2:#1C2225; /* плитки и переключатель */
  --edge:#272E32;    /* границы */
  --rail:#1F2528;    /* пустая часть слайдеров и полос диаграммы */

  --brand:#E2231A;   /* фирменный красный: знак, чистая прибыль, активный режим */
  --brand-dim:rgba(226,35,26,.16);   /* ореол вокруг ползунка при захвате */
  --brand-glow:rgba(226,35,26,.32);  /* свечение активной пилюли режима */

  --paper:#EDF0F2;   /* основной текст */
  --dust:#7C858B;    /* подписи на тёмном фоне */
  --dust-2:#9BA4AA;  /* подписи на панелях */

  --flow-1:#C2CACF;  /* валовой доход */
  --flow-2:#8E979D;  /* комиссия УК */
  --flow-3:#6B747A;  /* операционные расходы */
  --flow-4:#4C5459;  /* налог */
}
```

Правила, которые стоит сохранить при перекраске:

- **Один акцент на страницу.** Вычеты различаются светлотой одного нейтрала (`--flow-1..4`),
  а не разными цветами. Диаграмма поэтому читается даже в чёрно-белом.
- **Контраст.** `--dust` рассчитан под фон `--panel` (4.7:1), `--dust-2` — под `--panel-2` (6.3:1).
  Меняя фоны, пересчитайте подписи, иначе провалится WCAG AA.
- **Радиусы** заданы в `--r-card` / `--r-input` / `--r-pill` и нигде не пишутся числом.

Меняя `--brand`, обновите заодно два места, где красный записан явно:
favicon в `<link rel="icon">` (data-URI) и `og-source.html`, после чего пересоберите `og.png`.

## Деплой

Калькулятор живёт на GitHub Pages: **https://parkerspb24-coder.github.io/phuket-yield-calculator/**

Обновление — обычный push в `main`, Pages пересобирает страницу сам за минуту:

```bash
git push origin main
```

Если поднимаете копию под другой аккаунт или филиал:

```bash
gh repo create <репозиторий> --public --source=. --remote=origin --push
gh api -X POST repos/<аккаунт>/<репозиторий>/pages -f "source[branch]=main" -f "source[path]=/"
```

После этого обязательно перепишите два мета-тега в `index.html` под новый адрес,
иначе соцсети покажут превью и ссылку старого сайта:

```html
<meta property="og:url" content="https://<аккаунт>.github.io/<репозиторий>/">
<meta property="og:image" content="https://<аккаунт>.github.io/<репозиторий>/og.png">
```

Относительный путь к `og.png` тут не работает: краулеры соцсетей требуют абсолютный адрес.

## Формулы

Логика расчёта повторяет исходный референс один в один.

```
gross      = краткосрочная ? суточная_цена × дни_заполняемости : месячная_ставка
mgmt_fee   = gross × комиссия_УК%          // только в краткосрочном режиме
after_mgmt = gross − mgmt_fee
taxable    = max(0, after_mgmt − opex)
tax        = taxable × налог%
net        = after_mgmt − opex − tax
net_year   = net × 12
payback    = стоимость / net_year          // net_year ≤ 0 → «не окупается»
yield      = net_year / стоимость × 100
```

Сценарии окупаемости:

- краткосрочная аренда: оптимистичный — 30 дней заполняемости, средний — текущая,
  пессимистичный — половина текущей, но не ниже 5 дней (нижняя граница слайдера);
- долгосрочная аренда: оптимистичный — ставка +20%, средний — текущая, пессимистичный — −20%.

**Комиссия управляющей компании в долгосрочном режиме не удерживается** — так устроен референс.
Слайдер в этом режиме отключается и подписывается, чтобы поведение не выглядело багом.

## Поведение

- Пересчёт мгновенный, без кнопки. Числа доезжают до нового значения за 450 мс с easing;
  новый ввод отменяет предыдущую анимацию, а не накладывается на неё.
- Состояние пишется в хэш адреса, поэтому расчётом можно поделиться ссылкой.
  Кнопка «Скопировать расчёт» кладёт в буфер текстовую сводку вместе со ссылкой.
- `prefers-reduced-motion: reduce` выключает всю моцию: числа встают в цель мгновенно,
  состояния и фокус остаются на месте.
- Mobile-first, проверено на 380 px. Учтены `viewport-fit=cover` и `env(safe-area-inset-*)`
  для запуска внутри Telegram Mini App.

## Локальный запуск

```bash
python -m http.server 8777
# http://127.0.0.1:8777/index.html
```

Файл открывается и просто двойным кликом, но через сервер корректнее работают
шрифты и запись состояния в адрес.
